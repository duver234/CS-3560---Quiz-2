<h2>Instructions and Info.</h2>

This repository contain two programs, the Calculator program that performs basic arithmetic, and the DateChecker program that checks if the month inputted has 30 days or not.
<br><br>The tests available can be run for each of the two programs in their respective "test" files.
<br><br>For the Calculator program, there will be tests for the basic arithmetic methods, and for invalid inputs and exceptions.
<br><br>For the DateChecker program, there will be tests about the correct dates that have the 31 days or not, as well as a test for whether or not the input is valid.
<br><br>
